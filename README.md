# مِداد | MIDAD

واجهة ويب عربية RTL لمنصة الابتكار الجامعي، بتصميم داكن فاخر مستوحى من التصور المرئي المعتمد.

## المتطلبات
- Node.js 20 أو أحدث
- npm
- (اختياري) Docker لتشغيل قاعدة البيانات والـ backend الموجودين في مجلد backend

## تشغيل الواجهة
من داخل مجلد المشروع:

```bash
npm install
npm run dev
```

ثم افتح: http://localhost:3000

## ما يعمل في الواجهة الحالية
- لوحة رئيسية عربية متجاوبة.
- استعراض بنك المشكلات والبحث فيها.
- إضافة مشكلة جديدة من نافذة تفاعلية.
- التصويت على المشكلات (محليًا أثناء جلسة الصفحة).
- استعراض الفرق وإرسال طلب انضمام تجريبي.
- صفحات المشروعات والفرص والملف الشخصي.

> ملاحظة: هذه النسخة هي واجهة Frontend تفاعلية ببيانات تجريبية محلية؛ لم يتم ربط عناصر هذه الواجهة الجديدة بعد بنقاط الـ API الموجودة في مجلد backend. لذلك لا تُعد بيانات التصويت والإضافة بيانات دائمة بعد تحديث الصفحة.

## بنية المشروع
- `app/page.js` واجهة التطبيق والتفاعلات.
- `app/globals.css` التصميم والألوان والتجاوب مع الجوال.
- `app/layout.js` إعدادات الصفحة واللغة.
- `backend/` بداية Backend باستخدام FastAPI وPostgreSQL من النسخة السابقة.
- `docker-compose.yml` إعداد قاعدة البيانات.
- `midad-logo.png` الشعار التصوري.

## البناء للإنتاج
```bash
npm run build
npm run start
```

للنشر العام، ارفع المجلد إلى GitHub ثم اربطه بخدمة استضافة Next.js مثل Vercel. يلزم إعداد وربط Backend وقاعدة بيانات مستضافة قبل استخدام بيانات حقيقية أو استقبال حسابات طلاب.
